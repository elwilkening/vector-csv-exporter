# Contributing to Vector CSV Exporter

Thanks for your interest in contributing! A few quick guidelines to help your contribution be accepted smoothly.

## Reporting issues
- Open a clear issue describing the bug or feature request.
- Provide steps to reproduce, sample data if possible, and relevant QGIS version.

## Code contributions
- Fork the repository and create a feature branch.
- Keep changes small and focused; include tests or sample data where practical.
- Follow the existing code style and naming conventions.

## Pull requests
- Target the `main` or `master` branch depending on repo conventions.
- Describe the change and why it's needed in the PR description.
- Link any relevant issues.
